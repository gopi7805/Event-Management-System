
# Event Ticketing System

## About the Project
A Full Stack web application developed to display events and manage event ticket bookings.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- REST APIs
- Postman

## Features
- Display available events.
- Manage event details.
- Manage ticket bookings.
- Store event and booking information in MySQL.
- Connect frontend with backend APIs.

## Backend
- Spring Boot
- Spring Data JPA
- RESTful APIs
- MySQL Database Integration

- JavaScript
